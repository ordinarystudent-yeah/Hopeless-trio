# 별빛스프 — 인터랙티브 웹 동화책

아이가 이름을 적고, 음식을 고르거나 직접 그리고, 착한 일을 이야기하면 그 내용이 동화 속 문장과 그림에 들어가는 10장면 웹 동화책입니다.
장면 하나는 펼친 책 한 면, 즉 **가로 A4 두 쪽**(왼쪽 쪽 + 오른쪽 쪽)입니다. 넓은 가로 화면에서는 펼침면 전체를, 휴대폰과 세로 화면에서는 한 쪽씩 넘겨 봅니다.
서버 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 실행

```bash
# 폴더에서 아무 정적 서버나 사용 (파일을 더블클릭해서 열어도 동작합니다)
cd storybook
python3 -m http.server 8000
# → http://localhost:8000
```

## 파일 구조

```
storybook/
├─ index.html        화면 뼈대 (진행 표시, 책, 이전/다음 버튼, 그림 편집기, 알림, 확인창)
├─ css/style.css     디자인 토큰, 펼침면 책 레이아웃, 스티커, 누르는 느낌
├─ css/editor.css    그림 편집기 화면
├─ js/story.js       ★ 동화 문장 · 음식 · 맛 · 이미지 경로 설정 (내용 수정은 여기서)
├─ js/storage.js     진행 기록(localStorage) · 그린 그림(IndexedDB) 저장
├─ js/drawing.js     그림 편집기 (펜·연필·브러시·지우개·페인트 통·사진·실행 취소)
├─ js/main.js        책 그리기, 장면 넘기기, 입력, 스티커
└─ assets/           삽화 파일을 넣는 곳
```

## 삽화 넣기

`js/story.js`에 적힌 경로대로 파일을 넣으면 코드 수정 없이 바로 바뀝니다.
파일이 없으면 임시 그림이 나오고, 왼쪽 위에 "펼침면 삽화 자리 · 경로"가 표시됩니다.
모든 삽화를 넣은 뒤에는 `story.js` 맨 아래 `showAssetNotes`를 `false`로 바꾸세요.

장면 삽화는 **펼침면 한 장**(왼쪽 쪽 + 오른쪽 쪽을 이어 그린 그림)입니다.
비율은 594:210(약 2.83:1)이며, 예를 들어 4200×1485px 또는 인쇄용 300dpi 기준 7016×2480px로 만들면 됩니다.
가운데 접히는 부분(제본선)에는 중요한 그림이나 얼굴을 두지 마세요. 본문 글이 들어가는 쪽은 `pages` 설정에서 확인할 수 있습니다.

## 이야기 속 개인화

- 이름을 입력하면 이후 장면의 "당신"이 이름으로 바뀌고, 조사(이/가, 은/는, 을/를)도 받침에 맞춰 자동으로 붙습니다.
- 고른 음식은 #5 문장("그렇게 푸딩을 먹다 보니…")에 들어갑니다.
- 착한 일을 비워 두면 #7은 별도의 기본 문장을 사용합니다.
- 맛은 엔딩 문장에 들어가고, 엔딩의 기록 카드에서 "고치기"를 누르면 해당 장면으로 갔다가 바로 엔딩으로 돌아옵니다.
- 사용자 입력은 항상 `textContent`로만 화면에 넣으므로 HTML로 해석되지 않습니다.

## 음식 그리기와 스티커

- #4에서 음식 카드를 고르면 그 음식이 스티커가 되어 오른쪽 쪽에 붙습니다. 바로 다음 장면으로 넘어가지 않습니다.
- 스티커는 끌어서 옮기고, 노란 손잡이로 크기와 방향을, 빨간 ×로 떼어낼 수 있습니다. 위치는 저장됩니다.
- "직접 그리기" 카드를 누르면 그림 편집기가 열립니다. 사진을 찍거나 앨범에서 골라 넣을 수도 있습니다.
  다 그리면 그림이 있는 부분만 잘라 투명 배경 스티커가 되고, 카드에도 그 그림이 나옵니다. 고른 상태에서 한 번 더 누르면 이어서 그립니다.
- #6에서도 "그림이나 사진으로 꾸미기"로 착한 일 그림을 그려 스티커로 붙일 수 있고, 이 그림은 #7에도 나옵니다.
- 그림 편집기: 펜·연필·브러시·지우개·페인트 통, 굵기, 색 팔레트와 색상 휠, 실행 취소(15단계, Ctrl+Z), 전체 지우기·새로 시작(항상 확인창).

## 조작

- 이전/다음 버튼, 키보드 ← → 키(입력 중이 아닐 때), 상단 진행 표시의 칸(이미 읽은 장면만)
- 장면이 바뀔 때는 카드처럼 호(약 22°)를 그리며 넘어가고, 한 쪽씩 보기에서 같은 장면의 쪽을 넘길 때는 옆으로 밀려납니다.
- 버튼과 카드는 누르는 순간 살짝 작아지고 떼면 부드럽게 돌아옵니다.
- 음식과 맛은 고르지 않으면 다음으로 넘어가지 않고 안내 문구가 나옵니다. 이름과 착한 일은 비워도 됩니다.
- 진행 기록은 이 기기의 브라우저에만 저장되며, 다시 열면 "이어서 읽기"를 물어봅니다.
