### 공유 링크 켜기 (GitHub Pages, 처음 한 번만)

1. 저장소의 **Settings → Pages**로 갑니다.
2. **Build and deployment → Source**를 `Deploy from a branch`로 둡니다.
3. **Branch**에서 `claude/vibe-coding-session-p3ia7d` (나중에 main에 합친 뒤에는 `main`), 폴더는 `/ (root)`를 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 위 링크로 열립니다. 이후에는 그 브랜치에 올릴 때마다 자동으로 새 버전이 반영됩니다.
